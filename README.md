# Python Beginner Projects

This repository contains two small command-line Python programs for beginners.

## 1. Simple Calculator (`calculator.py`)

The calculator asks for two numbers and an operator, then performs addition, subtraction, multiplication, or division. It also checks for division by zero and invalid operators.

## 2. Greeting Bot (`greeting_bot.py`)

The greeting bot asks the user for their name and responds with a personalized greeting. It uses an **f-string** and an **if-else** condition. If the user enters a blank name, it displays a friendly default greeting.

## Requirements

- Python 3.6 or newer
- No external libraries required

## How to Run

Open a terminal in this folder and run:

```bash
python calculator.py
```

To run the greeting bot:

```bash
python greeting_bot.py
```

On some systems, use `python3` instead of `python`.

## Concepts Practised

- `input()` and `print()`
- Variables and numeric conversion with `float()`
- `if`, `elif`, and `else`
- Arithmetic operators
- f-strings
- Basic input validation
